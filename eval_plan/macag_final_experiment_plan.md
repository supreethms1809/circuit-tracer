Ground rules:

## 3. Primary experiments (run first)

### P1. Graphs, and the diagnostic on every prompt

- **Prompts per CLT:** 25 IOI + 25 MCQA + 25 ARC = **75**.
- **Diagnostic:** R_frozen and R_unfrozen from all/empty scores (4 forwards per prompt), giving the verdict.
- **Verdict rule:** the pre-registered strict-sign rule. Amendment: the (0, 0) corner is indeterminate.
- **Dead band:** margin m = max |ΔR| across the S1 reruns. This procedure is fixed now; the value comes from S1. Verdicts are reported at margin 0 and at m.
- **Presented:** T2 verdict counts with Wilson 95% CIs per CLT × task. F1 scatter of R_frozen vs R_unfrozen.
- **Tests:**
  - Fisher exact, Gemma (each CLT) vs Llama on IOI.
  - Fisher exact, Gemma IOI vs Gemma MCQA (within model).
  - Holm across these 4.

### P2. Game 1 against Track A baselines

- **Prompts:** the same 75 per CLT, all 3 CLTs.
- **Runs per prompt:**
  - Game 1, dual freeze.
  - Every baseline scored on **both** legs, each at that leg's matched k = |E\*| of the leg.
- **Baselines (Track A):**
  - random-k: mean over 10 seeded draws.
  - influence: labelled "graph influence (top-logit objective)".
  - eap_syed: feature AtP on the target−foil gap.
  - **singleton**: top-k by single-feature intervention, under the capped v.
  - ported ACDC: matched-k, |S| ≤ k, never oversized.
  - Graph EAP is dropped.
- **Degenerate legs (D2):** a leg with R ≤ 0 is excluded from that leg's head-to-head and counted in T2. Every cell enters the table on its **primary leg**: frozen if non-degenerate, else unfrozen if non-degenerate, else excluded. Both per-leg tables are also given in the appendix.
- **Metrics:**
  - capped F (confirmatory),
  - KL faithfulness (secondary family),
  - reported alongside: capped S, capped N, N/R, `keep_distance`, `remove_below_empty`, set sizes,
  - F-vs-k curves up to k = 128 for the ranking methods.
- **Presented:** T3 head-to-head per CLT × task: wins/n, median difference, bootstrap 95% CI, Holm-adjusted p. F2 F-vs-k curves.

### P3. Game 2 (one-sided)

- **Prompts per CLT:** 20 IOI + 20 MCQA, a subset of P2. All 3 CLTs.
- **Runs per prompt:** ABR at β = 0 and β = 0.2.
- **Measured:**
  - overlap,
  - shared, target-only and foil-only counts,
  - each agent's capped faithfulness,
  - convergence rate and `best_iteration`.
- **Test (secondary family):** paired β = 0.2 vs β = 0 on overlap, per CLT × task (6 tests, Holm).
- **Presented:** T4.

## 5. Statistics (D7)

- **Unit:** the prompt, within CLT × task. No pooling across CLTs.
- **Confirmatory family:**
  - comparisons: Game 1 vs {singleton, eap_syed, influence, random},
  - metric: capped F on the primary leg,
  - 3 CLTs × 3 tasks × 4 = **36 tests**,
  - paired two-sided Wilcoxon, **Holm across all 36**,
  - report wins/n, median difference, bootstrap CI.
  - At n = 25 the smallest attainable p is far below the Holm threshold. v4 subsampling showed 100% power at n = 15 for the effects seen so far.
- **Secondary families, each Holm'd within itself:**
  - KL at matched k (36 tests),
  - Game 2 β effect (6 tests),
  - diagnostic Fisher tests (4 tests).
- **Exploratory:** everything else, labelled as such. That includes ACDC, per-leg tables, Shapley agreement, and S2–S8.
- **Robustness:** per-stratum results are shown in full. A claim is called robust only if it holds in every CLT for that task.

## 7. Compute and scheduling

**Allocation:** 15 nodes total, 5 per CLT, 2 GPUs per node, 4 workers per GPU = **40 worker slots per CLT**.

**Rate:** v4 measured about 1.3–1.6 oracle calls/s per worker at this concurrency.

**Order:** Phase P (P1 → P2 → P3) runs to completion before Phase S starts.

**Schedule:**
- Phase P2: 75 prompts per CLT, about 2 per slot.
- Phase P3: 40 prompts per CLT, **exactly 1 per slot**.
- Tasks are assigned longest-first from pilot costs. Prompts are chosen by seed, never by cost.

**Rough wall-clock (v4 costs, to be re-estimated from the pilot):**
- graph building: measure in the pilot,
- P2: about 2–3 days,
- P3: about 2–4 days,
- Phase S: about 2–3 days.

**Pilot (before launch):** 2 prompts per CLT × task through P1–P3. Checks:
- `code_version`, caps, `one_sided`, `matched_k_status` and token ids in the outputs,
- measured cost per task, used to build the longest-first assignment.

### 8.1 Group A: must be done before the pilot (changes raw outputs)

**A1. Score baselines on both freeze legs** (P2; plan "every baseline on both legs").
- **Now:** `run_baselines` builds one oracle from the kwargs (`freeze_attention: true`), and the pipeline calls it once, so every baseline is frozen-only.
- **Needed:** for each leg in {frozen, unfrozen}, evaluate every method's prefixes under that leg's oracle. Write per-leg blocks, e.g. `methods.<m>.legs.{frozen,unfrozen}.results[k]`.
- The **singleton ranking is oracle-dependent**, so compute it per leg.
- influence, eap_syed and random rankings are leg-independent. Compute them once and evaluate per leg.
- The pipeline either passes `--legs both` or runs the harness twice with freeze overrides.

**A2. ACDC target size = Game 1's per-leg |E\*|** (P2 ACDC matched-k).
- **Now:** `--acdc-target-k` is either an integer or `-1 = --budget` (128).
- **Needed:** a mode that reads `macag_game1.json` and uses each leg's |E\*|, skipping legs marked `degenerate`. Record `achieved_k` and `exact` per leg.
- Requires Game 1 to finish before the baselines stage; the pipeline already orders them this way.

**A3. random-k = mean of 10 seeded draws** (P2).
- **Now:** `select_random(candidates, seed)` gives one draw (`--random-seed`).
- **Needed:** `--random-draws 10`, giving draws with seeds `seed..seed+9`, each evaluated at every k. Report the per-k mean and SD, keep the per-draw values, and use the draw-mean in tests.

**A4. Matched-k availability.**
- Prefix results run k = 1..`--budget`, with the pipeline report budget at 128.
- **Needed:** if a leg's |E\*| > budget, mark the method "unavailable at k" instead of silently reading 128. Use the same rule in A2 and A7.
- Set the report budget ≥ the largest expected |E\*|. v4's maximum was 75, so 128 is fine, but enforce the rule rather than assume it.

**A5. Wall-clock per stage** (C4 cost table).
- **Now:** outputs carry oracle calls and forward counts, but no timings.
- **Needed:** `time.perf_counter` around every selection and evaluation stage (Game 1 per leg, each baseline's selection and its evaluation, Game 2 per β, KL rescore), plus GPU type and worker concurrency, stored in each output's `stats`.

**A6. Game 2 freeze convention independent of Game 1** (P3: unfrozen).
- **Now:** `write_oracle_kwargs` writes `freeze_attention` from the global `FREEZE_ATTENTION` (default true). The one-sided `oracle_kwargs_game2.json` inherits it. `run_macag game2` has no freeze option.
- **Needed:** `GAME2_FREEZE_ATTENTION` (default false for this plan), written into the Game 2 kwargs and recorded in Game 2 `params`.

**A7. Game 2 β list with distinct outputs** (P3: β ∈ {0, 0.2}; S4: β = 1.0).
- **Now:** one `BETA` per pipeline run. Outputs are `macag_game2_<solver>.json` and `.ckpt.json`, so a second β would overwrite the first, and resume logic would treat it as done.
- **Needed:**
  - `GAME2_BETAS="0 0.2"`, looped,
  - outputs `macag_game2_<solver>_b<β>.json` and `.ckpt.json`,
  - resume keyed on (solver, β, one_sided),
  - `macag_game2.json` canonical-copy logic updated or retired,
  - β recorded in params (already is).

**A8. Game 2 per-agent degenerate marking** (P3).
- **Now:** Game 2 carries `is_degenerate` only inside each agent's metric dict. Nothing summarises it.
- **Needed:** a top-level `degenerate_target` / `degenerate_foil`, from each agent's own one-sided range (R = log p_all − log p_empty), so aggregation can exclude degenerate agents. The one-sided range has its own sign and can be ≤ 0 independently of the logit-gap range.

**A9. KL rescore of baselines per leg** (P2 secondary family).
- **Now:** `rescore_baselines` uses one oracle with the kwargs freeze (frozen) at the **frozen** leg's |E\*|.
- **Needed:** per leg, an oracle with that leg's freeze, at that leg's |E\*|, skipping degenerate legs, with `matched_k_status` per leg. Output keyed by leg.

**A10. KL rescore of Game 2 per β with Game 2's own oracle settings.**
- **Now:** it reads `macag_game2.json` (the ABR canonical copy) and builds the oracle from the **selection** kwargs (logit-gap, frozen).
- **Needed:** iterate over `macag_game2_<solver>_b<β>.json`, using `oracle_kwargs_game2.json`'s freeze. KL itself is target-free, so only the freeze and the file selection change.

**A11. Regenerate the campaign prompt file** (D6).
- **Needed:** `build_mib_benchmark_prompts.py --sample random --seed S --task-limit ioi=25 mcqa=25 arc_easy=25` for gemma2 and llama3, committed. The file also designates the subsets as metadata flags, chosen by a second seeded shuffle within the 25 and never by cost:
  - P3: 20 IOI + 20 MCQA,
  - S1: 20 cells,
  - S2: 20 IOI,
  - S3/S4: 10 IOI,
  - S6: 10 IOI,
  - S7: 2 IOI,
  - S8: 10 MCQA.
- **Check:** MCQA has only 50 validation rows, so 25 is half the split. That's fine; record it.

**A12. Diagnostic-only mode** (S2, S6; also lets P1 run before P2).
- **Now:** the verdict is only computed inside the dual Game 1 run.
- **Needed:** `run_macag diagnostic`. It computes all/empty under both freeze conventions (4 forwards), writes ranges, verdict and `code_version`, and honours `--ablation-mode` (for S2) and the graph threshold (for S6).

**A13. Launchers for this plan** (Section 7).

  - KL rescore on,

- **Phase S:** separate launchers per S1–S8, each reading its subset flag.
- **Startup checks:** the launchers refuse to start if the git tree is dirty or HEAD is not the frozen tag.
- **Removed:** the old `cell % NUM_WORKERS` sharding (see A14).

**A14. Longest-first work assignment** (Section 7).
- **Now:** `run_macag_mib.sh` uses `(( cell % NUM_WORKERS == WORKER_ID ))`.

### 8.2 Group B: analysis code (finish during Phase P; freeze before reading results)

**B1. Aggregation script (new; replaces the frozen-only `experiments/analyze_macag_baselines.py`).**
- One row per (CLT, task, prompt, leg, method), at that leg's |E\*|, with:
  - capped F, capped S, capped N, N/R, `keep_distance`, `remove_below_empty`,
  - KL-F,
  - set size,
  - `matched_k_status`, degenerate flags.
- **Primary-leg rule (D2):** frozen if non-degenerate, else unfrozen if non-degenerate, else excluded.
- Game 2 rows per (prompt, β), excluding degenerate agents.

**B2. Verdict tables.** Recompute the verdict from stored ranges at margin 0 and at m (m from S1). Wilson CIs. Fisher tests.

**B3. Statistics script implementing Section 5 exactly.** It replaces the current blocks in `scripts/macag_bootstrap_wilcoxon.py` (pooled + strata × 3 families × 2 filters):
- **Confirmatory:** 36 tests on primary-leg capped F, with one Holm across all 36.
- **Secondary families:** KL (36), Game 2 β (6), Fisher (4), each with its own Holm.
- **Robustness rule:** "holds in every CLT for the task".
- **Exploratory:** labelled.
- Inputs only from B1.

**B4. Results generator.** One command produces T1–T5, F1, F2 and every appendix table from the raw JSONs via B1–B3, including the C5 uncapped table and the S1 reproducibility table. No hand-typed numbers.

**B5. Prompt representativeness check.** The sampled prompts vs the full split: IOI template and name-position mix, MCQA/ARC correct-answer position and foil-position balance.

**B6. S1 reproducibility comparison.** Per rerun cell: Game 1 set Jaccard per leg, verdict agreement, |ΔR|. Output m for B2.
